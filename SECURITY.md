# Security Policy

## Supported Versions

Only the latest release and the latest commits on the `main` branch receive active security updates. Older versions are not actively maintained.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| `main`  | :white_check_mark: |
| < 2.0   | :x:                |

We strongly recommend always running the latest version of Dawn FM.

---

## Reporting a Vulnerability

If you discover a security vulnerability or security bug in Dawn FM, please report it privately rather than opening a public issue or discussion.

### Contact

Please send an email detailing the vulnerability to:

**[wenujaweb@gmail.com](mailto:wenujaweb@gmail.com)**

To help us assess and resolve the issue quickly, please include:
- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions or a minimal Proof of Concept (PoC) to reproduce the issue.
- The operating system (e.g., macOS, Windows, Linux) and exact Dawn FM version/commit where the issue was observed.
- Any suggested fixes or mitigations, if known.

---

## Response & Disclosure Process

1. **Initial Acknowledgment:** We aim to acknowledge receipt of your report within **48 hours**, along with an initial assessment of the issue.
2. **Investigation & Resolution:** We will keep you informed of our progress as we investigate and work on a fix.
3. **Coordinated Disclosure:** We follow coordinated vulnerability disclosure. We ask that you give us **30 to 90 days** (depending on severity and complexity) to produce, test, and distribute a fix before disclosing any details publicly.
4. **Credit:** With your permission, we will gladly credit you in the release notes once the patch is published.

---

## Out of Scope

The following areas are generally out of scope:
- Vulnerabilities or infrastructure issues related to third-party services (such as YouTube, YouTube Music, Google, Spotify, or Apple Music servers).
- Attacks that require root/administrator privileges or physical access to an already-compromised device.
- Denial of service attacks against personal devices or network connections.
- Automated vulnerability scanner reports without a working proof of concept demonstrating practical impact.
